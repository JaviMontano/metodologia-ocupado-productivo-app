# QA Strategy

## Estrategia

La calidad se asegura con BDD para journey, TDD para motor deterministico y ATDD para criterios visibles de aceptacion. [DOC]

## Gates

1. Link integrity.
2. JS syntax.
3. No external calls.
4. Storage and reset.
5. Export contracts.
6. Desktop and mobile smoke.

## Evidencia requerida

Resultados de comandos locales, smoke de navegador y matriz de trazabilidad actualizada. [CONFIG]
