# Epics and Stories

## Epic 1 Diagnostico

Historia: como usuario quiero registrar actividades y clasificarlas para visualizar mi semana real.

Criterios: actividades editables, score visible, cuadrantes actualizados.

## Epic 2 Debate

Historia: como usuario quiero preguntas socraticas derivadas del diagnostico para tomar una decision.

Criterios: preguntas visibles, decision persistida.

## Epic 3 Plan semanal

Historia: como usuario quiero convertir la decision en prioridad, deep work, batch, buffer y no deliberado.

Criterios: cinco campos persistidos y exportados.

## Epic 4 Export y handoff

Historia: como usuario quiero descargar Markdown y JSON para continuar en BMAD/BMAP.

Criterios: archivos generados localmente y parseables.

## Epic 5 Reset

Historia: como usuario quiero limpiar sesion para iniciar otro diagnostico.

Criterios: estado local borrado y UI reiniciada.
