# PRD

## Objetivo

Permitir que un unico usuario complete diagnostico, debate socratico, plan semanal y exportacion BMAD/BMAP desde un repo estatico. [DOC]

## Historias principales

1. Como usuario quiero abrir la app sin login para empezar sin friccion.
2. Como usuario quiero registrar actividades para ver mi semana real.
3. Como usuario quiero clasificar impacto y energia para diferenciar ocupacion de productividad.
4. Como usuario quiero preguntas socraticas para convertir diagnostico en decision.
5. Como usuario quiero planear deep work, batching y buffers para ejecutar la siguiente semana.
6. Como usuario quiero exportar Markdown y JSON para reutilizar mi resultado.
7. Como usuario quiero limpiar sesion para reiniciar desde cero.

## Metricas pedagogicas

1. Actividades capturadas.
2. Horas clasificadas.
3. Decision escrita.
4. Plan semanal completo.
5. Export realizado.
