Uso academico y privacidad. Esta mini app es un material academico de MetodologIA. Opera sin login y guarda datos base solo en el navegador. El chatbot Gemini es opcional y solo llama la API externa cuando el usuario pega su propio API token. No apto para produccion sin validacion legal, tecnica, regulatoria y de seguridad. El API token no se exporta en BMAD/BMAP y no debe compartirse en GitHub. [CONFIG]
Paso 01

Preparar entorno

Confirmar Node 20+, Git, GitHub CLI, Antigravity y repo limpio. [CONFIG]

node -v
npm -v
gh auth status
git status --short
antigravity --version
Paso 02

Instalar BMAD

Instalar BMM+BMB+TEA para Antigravity y Codex. [CONFIG]

npx bmad-method install --yes \
  --modules bmm,bmb,tea \
  --tools antigravity,codex \
  --user-name "Javier Montaño" \
  --communication-language es \
  --document-output-language es \
  --output-folder _bmad-output
Paso 03

Ejecutar bmad-help

Abrir el repo en Antigravity y pedir la ruta siguiente. [CONFIG]

antigravity -n .
