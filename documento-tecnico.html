Blueprint tecnico independiente

Arquitectura estatica con IA opcional, controlada desde el navegador.

Este blueprint describe runtime, componentes, datos, seguridad, Gemini BYOK, multimodalidad, function calling local, exportadores, resiliencia, observabilidad y pruebas. [CONFIG]

Disclaimer tecnico. El repo es academico y estatico. La app base opera sin API externa. El asistente Gemini usa una llamada externa solo cuando el usuario pega un token propio desde pantalla. Para produccion se requiere validacion legal, tecnica, regulatoria, de seguridad y privacidad. [DOC]

01

Decision de arquitectura

La solucion es una aplicacion estatica de navegador: HTML, CSS, JavaScript plano y JSON local. No requiere build, servidor Node, framework, base de datos, cuenta de usuario ni backend para la experiencia base. [CONFIG]

DecisionMotivoAlternativa descartadaConsecuencia
SPA estatica ligera. [CONFIG]Hostinger puede servir archivos tal cual. [SUPUESTO]Framework con build. [INFERENCIA]Menos dependencias, mas responsabilidad manual en JS. [INFERENCIA]
Persistencia en navegador. [CONFIG]Privacidad local y uso sin login. [DOC]Base de datos remota. [INFERENCIA]El usuario controla limpieza y no hay sincronizacion multi-dispositivo. [CONFIG]
Gemini BYOK opcional. [CONFIG]El taller puede operar sin backend y sin secreto del repo. [DOC]API key commiteada o proxy propio. [CONFIG]No es patron productivo para keys reales en cliente. [DOC]
Function calling local allowlisted. [CONFIG]Permite que Gemini use contexto real sin dar acceso arbitrario. [DOC]Ejecutar comandos o codigo dinamico. [CONFIG]La superficie de tools es pequena y testeable. [CONFIG]

04

Gemini API, archivos y modos de analisis

Google AI Studio permite crear y administrar API keys; la API Gemini soporta prompts multimodales con texto, imagenes y documentos. La app usa REST generateContent para no depender de SDKs ni bundlers. [DOC]

TipoMIME aceptadoTratamientoModo recomendado
Textotext/plain, text/markdown, application/json, text/html. [CONFIG]Se agrega como parte text con encabezado de archivo. [CONFIG]Facilitador o anexo. [CONFIG]
PDFapplication/pdf. [DOC]Se agrega como inline_data. [CONFIG]Analisis de anexo. [CONFIG]
Imagenimage/png, image/jpeg, image/webp. [DOC]Se agrega como inline_data. [CONFIG]Identificacion visual controlada. [CONFIG]
No soportadoOtros MIME. [INFERENCIA]Se clasifica como no soportado y no se promete analisis. [CONFIG]Degradado. [CONFIG]
 
Usuario pega token -> saveToken()
Usuario carga archivos -> FileReader -> classifyFiles()
Usuario envia pregunta -> buildPayload()
  -> contents.parts[text + inline_data]
  -> tools.functionDeclarations
  -> POST /v1beta/models/{model}:generateContent
  -> respuesta directa o functionCall
  -> executeToolCall()
  -> functionResponse
  -> respuesta final al usuario
04.5

Inicializacion IA del entorno

El flujo del workshop empieza por token y luego por inicializacion IA. El navegador no ejecuta comandos de sistema; Gemini vitamina el entorno generando comandos copiables, prompts para bmad-help, checklist de readiness y handoff. [CONFIG]

API key en pantalla -> renderTokenStatus()
  -> Vitamina e inicializa con IA
  -> loadRepoContext()
  -> modo tools
  -> Gemini + function calling local
  -> salida de inicializacion
  -> handoff BMAD/BMAP sin token

06

Seguridad y privacidad

Google advierte que las API keys deben tratarse como contrasenas y que una key real no debe exponerse directamente en apps web o moviles de produccion. Esta app conserva el patron BYOK solo para el contexto academico y documenta el salto productivo necesario. [DOC]

ControlImplementacionValidacion
No secretos en repo. [CONFIG]No hay token hardcoded y `.gitignore` cubre `.env`. [CONFIG]Busqueda negativa de patrones de API key Google. [CONFIG]
Token por sesion. [CONFIG]sessionStorage por defecto. [CONFIG]Recargar conserva; cerrar pestana limpia. [INFERENCIA]
Recordar explicito. [CONFIG]localStorage solo si checkbox esta activo. [CONFIG]UI muestra estado recordado. [CONFIG]
Borrado visible. [CONFIG]Boton borra claves Gemini. [CONFIG]Estado vuelve a bloqueado. [CONFIG]
Exports sin token. [CONFIG]Handoff serializa metadata, transcript y app state, no token. [CONFIG]Tests buscan ausencia de token y patrones. [CONFIG]
Imagenes responsables. [SUPUESTO]Prompt prohibe identificacion personal e inferencias sensibles. [CONFIG]Smoke revisa instrucciones del modo imagen. [CONFIG]

08

Observabilidad local

La observabilidad se mantiene dentro del navegador: estado de token, lista de archivos, contexto cargado, transcript, tool traces y handoff generado. No hay telemetria remota. [CONFIG]

Estado visible

El workshop muestra si Gemini esta bloqueado, activo en sesion o recordado en navegador. [CONFIG]

Archivos clasificados

Cada anexo muestra MIME, peso, kind y capacidad. [CONFIG]

Tool traces

Cada function call local queda registrada en memoria del taller y en handoff sin secretos. [CONFIG]
