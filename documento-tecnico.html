Documento tecnico independiente

Arquitectura estatica, sin backend, lista para Hostinger.

Describe runtime, estructura de archivos, modelo de datos, motor de diagnostico, almacenamiento, exportadores, reset y validacion. [CONFIG]

Privacidad local. Esta mini app es un material academico de MetodologIA. Opera sin login, guarda datos solo en el navegador y no envia informacion a servidores. El diagnostico es orientativo y no sustituye acompanamiento profesional, medico, psicologico, legal ni laboral.

Decision de arquitectura

La solucion es una aplicacion estatica de navegador. Usa HTML, CSS, JavaScript plano y JSON local; no requiere Node, framework, transpilacion, servidor, base de datos, credenciales ni API externa para operar. [CONFIG]

Persistencia

assets/storage.js encapsula lectura, escritura y limpieza. La clave de almacenamiento es metodologia.ocupadoProductivo.session.v1. La app nunca necesita cookies ni sesion remota. [CONFIG]

Motor de diagnostico

assets/diagnostic-engine.js calcula horas totales, cuadrantes impacto/energia, indice productivo, riesgo de rueda de hamster, deuda de foco, carga operativa y energia neta. El algoritmo pondera impacto, energia e interrupciones para producir una orientacion pedagogica, no una verdad clinica o laboral. [CONFIG]

Exportadores

assets/exporters.js crea dos contratos de salida: bmad-input.md para lectura humana y bmap-session.json para pipelines agenticos. Ambos se generan localmente con Blob y descarga del navegador. [CONFIG]

Compatibilidad Hostinger

El repo completo puede subirse por File Manager o FTP manteniendo rutas relativas. El archivo de entrada debe quedar como public_html/index.html o dentro de una subcarpeta preservando assets/, data/, prototipos/, specs/, quality/ y bmap/. [CONFIG]
