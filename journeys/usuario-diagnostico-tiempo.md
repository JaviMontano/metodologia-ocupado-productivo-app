# Journey unico: usuario diagnostico de tiempo

## Usuario

Cualquier persona que quiere entender como usa su tiempo, pasar de ocupado a productivo y exportar resultados para un flujo BMAD/BMAP.

## Recorrido

1. Abre `index.html` sin login.
2. Lee proposito y privacidad local.
3. Ingresa o pega actividades de la semana.
4. Clasifica cada actividad por impacto, energia, tipo e interrupciones.
5. Recibe diagnostico de ocupacion vs productividad.
6. Responde debate socratico guiado.
7. Disena una semana de alto impacto.
8. Exporta Markdown y JSON para BMAD.
9. Limpia sesion para reiniciar.
10. Sube el repo completo a Hostinger si esta en taller tecnico.

## Criterio de exito

El usuario termina con una decision, un plan semanal y un paquete exportable que puede entregar a un pipeline agentico.
