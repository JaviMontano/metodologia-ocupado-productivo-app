# Acceptance Criteria

## Criterios globales

1. El usuario puede completar el journey de inicio a export sin cuenta. [CONFIG]
2. La app explica privacidad local antes de capturar datos. [DOC]
3. La app no sube informacion a servidores. [CONFIG]
4. La salida BMAD/BMAP es util como input de pipeline posterior. [SUPUESTO]
5. El repo puede subirse completo a Hostinger sin build. [CONFIG]

## Criterios por estacion

1. Diagnostico: al menos una actividad produce score y cuadrantes.
2. Debate: hay preguntas visibles aun sin datos y preguntas especificas con datos.
3. Plan: los cinco campos persisten.
4. Export: Markdown y JSON reflejan estado actual.
5. Limpiar sesion: la app vuelve a estado inicial.
